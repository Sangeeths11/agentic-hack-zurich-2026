How scores work

Gemini returns the six criterion scores below. The server calculates the overall weighted sum, rounded to one decimal. Each criterion: 0 absent, 25 ambiguous, 50 plausible, 75 strong, 100 explicit evidence. Overall weights: family 5%, distress 10%, urgency 20%, secrecy 20%, financial request 25%, courier 20%. Below 50 green; 50 caution (amber); 75 high (red); 90 critical. Mistakes are possible. Verify independently.
