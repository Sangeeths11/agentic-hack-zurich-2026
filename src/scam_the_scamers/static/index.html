How scores work

Gemini assesses six criteria against the accumulated conversation. Each score: 0 absent, 25 ambiguous, 50 plausible, 75 strong, 100 explicit evidence. The server adds all six scores, caps the total at 100 and rounds to one decimal. Alerts start at 50 (caution), 75 (high) and 90 (critical). Gemini's scam judgment and a suspicious-number match can raise the alert level independently. Mistakes are possible. Verify independently.
